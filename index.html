MISSION 01CANYON RUN
ROUTE PREVIEW

ブリーフィング

🎯 目的：盆地の奥にある敵施設（リアクター）を爆撃して破壊せよ

  • ⚠ 高度（ALT）480 以上に上がると敵レーダーに捕捉され、SAM（地対空ミサイル）が一斉に発射される。谷の中から機体を出すな
  • 🟢 緑の点線矢印がルート。深い谷 → 大橋の架かる川の峡谷（橋の下をくぐれ）→ 山あいの谷 → 盆地の順に抜けろ
  • ⏱ 制限時間 --。巡航速度だけでは間に合わない。ブーストを使え（機体強化でも有利に）
  • 💣 目標の近くではミサイルボタンが爆弾に変わる（誘導爆弾4発）。2発命中で破壊
  • 🚀 目標を破壊したら離脱までが任務。新しく出る緑の矢印に沿って盆地を抜け、離脱ポイント（緑の光の柱）へ。盆地から出るため高度を上げると、敵ミサイルと高速の迎撃機が襲ってくる。かわしながら低く逃げるか、応戦してから離脱せよ
  • 盆地には対空砲台がある。これは最高難易度のミッションだ

報酬：初回クリア 4000 CR／2回目以降 1000 CR＋残り時間ボーナス
