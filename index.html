MISSION 01CANYON RUN
ROUTE PREVIEW

ブリーフィング

🎯 目的：盆地の奥にある敵施設（リアクター）を爆撃して破壊せよ

  • 🟢 奥の盆地に入れば高度制限はない
  • ⚠ 谷の上（尾根）には6連装ミサイル発射装置（SAM）が等間隔で並んでいる。高度（ALT）480 以上に上がるとレーダーに捕捉され、一斉に撃ってくる。谷の中から機体を出すな
  • 🟢 緑の点線矢印がルート。深い谷 → 大橋の架かる川の峡谷（橋の下をくぐれ）→ 山あいの谷 → 盆地の順に抜けろ
  • ⏱ 制限時間 --。巡航速度だけでは間に合わない。ブーストを使え（機体強化でも有利に）
  • 💣 目標の近くではミサイルボタンが爆弾に変わる（誘導爆弾4発）。2発命中で破壊
  • 🚀 目標を破壊したら離脱までが任務。新しく出る緑の矢印に沿って盆地を抜け、海岸の離脱ポイント（緑の光の柱）へ。高度を上げると敵ミサイルも飛んでくる。迎撃機をかわしながら低く逃げるか、応戦して全滅させよ
  • ⚠ 基地を破壊すると警報が鳴り、迎撃機が次々と発進する。離脱ポイントは東の海岸線。画面の緑の印を目指すか、迎撃機を全滅させれば任務完了。空母へ帰還せよ
  • このミッションでは EXファンネルは使えない。ブーストは常にソニックムーブ。最高難易度だ

報酬：初回クリア 4000 CR／2回目以降 1000 CR＋残り時間ボーナス
